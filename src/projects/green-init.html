Audit Methodology

The 4 Assessment Pillars

A multi-criteria diagnostic framework combining ecology, accessibility, and digital privacy.

01

Green Hosting

Verifying server geographical locations, low-carbon energy commitments, and recognized green datacenter labels.

02

Accessibility (WCAG)

Color contrast ratios, screen reader semantic markup, keyboard accessibility, and compliance with WCAG / RGAA guidelines.

03

Ethical Analytics

Strict GDPR compliance, privacy-first cookie-free traffic measurement (Matomo / Plausible) respecting user consent.

04

Code Quality & Eco-Index

Minimizing HTTP requests, payload weights, DOM node complexity, and asset optimization to conserve compute energy.
